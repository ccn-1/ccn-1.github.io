2026-05-25 · 5877 字 · 17 分钟

前言：为什么从《鱼书》开始

后续我准备跟随老师学习和研究“深度学习 + 联邦学习 + 推荐系统”方向。推荐系统看起来是在解决“该给用户推荐什么内容”的问题，联邦学习看起来是在解决“用户数据不能集中上传时怎么联合训练模型”的问题，但继续往下拆，它们最终都离不开深度学习中的几个基础问题：

  • 数据怎样表示；
  • 模型怎样根据输入给出判断；
  • 多层网络为什么比单层模型更强；
  • 输出结果怎样理解；
  • 后续模型怎样根据错误自动调整参数。

因此，我选择从斋藤康毅的《深度学习入门：基于 Python 的理论与实现》开始补基础。前三章没有直接进入训练过程，而是依次讲了：

这三章解决的是一个很关键的问题：

在模型真正开始“学习”之前，数据怎样进入模型，模型怎样完成一次判断，以及多层结构为什么有意义。

一、前三章知识总览：神经网络如何完成一次判断

《深度学习入门》前三章还没有正式讲模型如何训练，而是先建立了一个完整的推理框架：

数据如何表示
→ 最简单的判断模型如何工作
→ 多层结构为什么有必要
→ 真实图片如何经过网络得到分类结果

三章之间的关系可以概括为：

章节 核心内容 解决的问题

第 2 章 感知机、逻辑门、XOR 最简单的模型怎样根据输入作出判断，多层结构为什么出现

1.1 必须掌握的核心概念

概念 当前理解
NumPy 数组 用统一结构组织数据，并进行批量数值计算
shape 说明数据各个维度分别表示什么，例如 (100, 784) 表示 100 张展开后的 MNIST 图片
矩阵乘法 将原始输入重新组合成新的特征表示
广播 将同一组偏置等规则自动应用到整批样本
权重 不同输入因素对结果的重要程度
偏置 神经元整体上有多容易被激活，即对判断门槛的调整
激活函数 使网络能够表达复杂、非线性的判断关系
隐藏层 将原始信息转换成更适合最终任务判断的新表示
Softmax 将输出分数转换为概率形式，但不改变最大类别的位置
argmax 找到得分最高的类别索引
Batch 一次送入模型处理的一批样本

1.3 从 MNIST 到推荐系统的联系

在 MNIST 中，模型处理的是：

像素灰度值
→ 隐藏层形成图像特征
→ 输出层判断属于数字 0 到 9 中的哪一类

在推荐系统中，类似过程可以理解为：

用户行为、物品特征、当前场景
→ 隐藏层形成兴趣匹配、价格接受、重复疲劳等判断
→ 输出层给候选物品打分
→ 选择更适合用户的内容

真实推荐不应只是简单地认为：

用户喜欢科幻内容，就持续推荐科幻内容；
商品越热门，就越应该推荐。

模型更需要表达多个因素组合后的判断，例如：

内容符合兴趣，但用户近期已经反复看过同类内容，因此降低推荐优先级；
兴趣匹配，并且价格合适、当前场景合适、近期没有重复浏览，因此提高推荐概率。

因此，前三章最重要的收获不是记住若干函数，而是理解：

神经网络会将原始数字输入，通过权重、偏置、非线性激活与多层特征组合，逐步转化为最终决策依据。

它把原始分数变为总和为 1 的概率分布。

7.2 为什么推理时有时可以省略 Softmax

Softmax 不改变各类别分数的大小顺序，因此只取最大类别时，前后 argmax 结果一致。

十、目前解决的疑问整理

学习疑问 当前理解
NumPy 为什么重要？ 它负责把大量数据组织成数组，并进行批量矩阵计算，是神经网络底层计算基础。
Python 列表与 NumPy 数组有什么不同？ 列表更通用；NumPy 数组更适合统一类型的批量数学运算。
* 和 @ 有什么区别？ * 是对应位置相乘；@ 是综合加权的矩阵乘法。
广播是什么？ 较小数组按照规则自动应用到整批数据上，例如一组偏置加到所有样本。
AND 门为什么可以设置 theta=0.7？ 因为单个输入得分为 0.5，两个输入得分为 1.0，阈值只要处于二者之间即可。
为什么要引入偏置？ 偏置等价于将阈值移入公式左侧，用于控制神经元整体激活难度。
坐标系中的四个点从哪里来？ 两个逻辑输入各只能取 0/1，所以共有四种输入组合。
XOR 为什么不能由单层感知机实现？ 两类点无法被一条直线完全分开，即线性不可分。
XOR 如何严格推导为 AND、OR、NAND 的组合？ 从输出为 0 的两行构造主合取范式，再用德摩根律化为 AND(OR, NAND)。
为什么激活函数必须是非线性的？ 只有线性变换时，多层仍可合并为一层；非线性使模型能够表达复杂条件组合。
一个像素是否对应一个神经元？ 在当前全连接 MNIST 网络的输入层中，一个输入节点接收一个像素灰度值；隐藏层不再对应单个像素。
灰度图的 1 通道是什么意思？ 每个像素只需一个亮暗值描述；RGB 彩色图则需要三个颜色通道。
Softmax 是否会改变分类结果？ 只比较最大类别时不会改变 argmax 结果，但会将分数转换为概率形式。
np.argmax() 做什么？ 返回最大值的位置，即预测类别编号。
axis=1 表示什么？ 对二维数组的每一行横向比较，在 MNIST 中即为每张图片选择得分最高的数字类别。
